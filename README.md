# Arduino Binary Clock

An Arduino-based binary clock that uses a **DS3231 Real-Time Clock (RTC)** module to retrieve the current time and displays hours, minutes, and seconds using LEDs in binary format.

### Features

* Displays hours, minutes, and seconds in binary
* Uses the DS3231 RTC module for accurate time
* Updates the display every second
* Uses LEDs to represent individual binary bits
* Uses bitwise operations to determine LED states

### Components

* Arduino board
* DS3231 RTC module
* 16 LEDs
* Connecting wires
* Breadboard

### Concepts Used

Arduino programming, RTC communication, digital output, arrays, loops, and bitwise operations.
